# Chrome Web Store listing – Dibino Lens

**Name:** Dibino Lens
**Category:** Developer Tools
**Language:** English (+ Persian)

## Short description (≤132 chars)
Capture any web page's design – HTML, CSS, tokens, screenshots – as one clean package to hand to your AI tool.

## Detailed description
Dibino Lens turns any web page into a design package an AI (Claude, ChatGPT, Cursor…) can actually understand.

One click gives you:
• Clean rendered HTML + the CSS actually used
• Design tokens: colors, fonts, sizes, spacing, radius, shadows, animations
• Tailwind theme snippets (v3 and v4) and tokens.json
• Full-page screenshots: desktop, tablet, mobile, and per-section crops
• Images and fonts used on the page
• A ready-made prompt (HTML / Tailwind / React / Elementor, Persian or English)
• Pick-an-element mode, privacy mode (masks texts and inputs), ZIP or single Markdown output

Everything runs locally in your browser. Nothing is uploaded anywhere. Persian (RTL) and English interface.

## Single purpose
Extract the design (markup, styles, tokens, screenshots) of the page the user is viewing, into a downloadable file.

## Permission justifications
- activeTab: access the current page only after the user clicks the extension icon, to read its DOM/CSS and capture screenshots.
- scripting: inject the panel and extraction scripts into that page.
- storage: remember the user's chosen options and language.
- optional host permissions (http/https): requested per site, only when the user wants to fetch cross-origin stylesheets/images/fonts that the page cannot read itself.

## Privacy answers
- Collects no user data; no remote servers, analytics or remote code.
- Data stays on the device; output is a file the user downloads.
- Policy: see PRIVACY.md (host it publicly, e.g. GitHub Pages, and paste the URL).
